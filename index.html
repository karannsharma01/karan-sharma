How I think

Different models, same loop.

Start with the failure, not the model.

What breaks, for whom, and how often? A 504 timeout and a blurry output are different problems, even when both get called "the model is slow."

Numbers before opinions.

VRAM, latency, PSNR, SSIM. I pick the metric first, so every change either helps or it doesn't.

A model isn't done until it's deployed.

Containers, async queues, CI/CD, and limits that hold under load. Production is where the real evaluation happens.

Keep the loop short.

Papers, internships, side projects, and 150+ solved algorithm problems. Each one makes the next question sharper.
